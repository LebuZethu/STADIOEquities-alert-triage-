# Data

Datasets used in this project.

This folder holds both the raw proxy dataset(s) and any cleaned/processed
versions produced during data preparation.

- **Raw data** — the original dataset as downloaded, kept unmodified.
- **Processed data** — cleaned, feature-engineered data ready for modelling.

Note: large data files may be excluded from version control via `.gitignore`
and instead documented here with their source and download instructions.
